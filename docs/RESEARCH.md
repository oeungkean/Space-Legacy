# Space Legacy: Mission Research (Phase 1)

This table lists the missions used by the Spacecraft & Hardware Explorer and the mission replays.
Every fact here was checked against the linked source (mostly NASA pages) in October 2026.
If a fact could not be confirmed, it is either left out or marked "not verified".

**Stage letters** used by the replay system:
- **A** Launch
- **B** Journey
- **C** Landing, orbit or deployment
- **D** Return to Earth
- **E** Completion

A mission only gets the stages it really had.

## About the 3D models

Every 3D model in Space Legacy is a **representative model built in code**. None is an official NASA 3D model. Proportions follow the published sizes above where they are known; details are simplified. The Explorer labels each model "Representative model". Official photos are linked (not copied) on each detail page.
